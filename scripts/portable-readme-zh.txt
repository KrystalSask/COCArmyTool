COCArmyTool v{version} 便携版（Windows x64）使用说明
================================================

1. 启动
   - 双击 COCArmyTool.exe 即可运行，无需安装程序，也无需安装
     Node.js、Rust 或 Vite。
   - 本版本面向 Windows 10/11 64 位（x64）系统。
   - 需要电脑已安装 Microsoft Edge WebView2 运行时（Windows 11
     通常已自带；Windows 10 可在微软官网搜索 “WebView2 Runtime”
     免费安装）。

2. 数据存放位置
   - 便携版“免安装”只表示无需安装程序即可运行，数据并不随文件夹携带。
   - 配兵方案等本地数据保存在 Windows 每用户本地 AppData 目录
     （%LOCALAPPDATA%\com.cocarmytool.desktop）下的 WebView2 用户
     数据中；移动、重命名或删除本文件夹都不会影响已保存的数据。
   - 请定期在应用“方案库”中导出 JSON 备份，防止数据丢失。

3. 与开发版的区别
   - 本便携版是正式发布的桌面应用，不包含源码、测试、样本或开发工具。
   - 截图识别模型内置在应用中，识别完全在本机执行，不上传任何截图。

4. 已知限制
   - 当前只支持国服 18 级大本营的固定容量和常驻单位。
   - 内置热门方案是随版本发布的人工快照，不是联网实时榜单。
