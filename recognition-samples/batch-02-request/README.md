# 第二批覆盖样本采集请求

本批包含 4 套覆盖驱动配置，每套分别在 iPhone 17 和 iPad Pro 2024 11 英寸的准备进攻界面截图，共 8 张。

所有配置均由生成器强制满足可见类别上限：主军非攻城兵种不超过 11 类、主法术不超过 7 类、攻城机器类别不限、援军兵种/法术/攻城机器合计不超过 7 类。超过上限导致的游戏内遮挡不属于自动识别承诺范围，产品应提示玩家手工补充漏项。

## 采集步骤

1. 按 `labels.txt` 中的链接在对应设备打开并复制军队配置。
2. 确认游戏实际显示为 `352/352`、`11/11`、`3/3`、援军 `55/55 + 4/4 + 2/2`，并显示四位英雄、战宠和装备。
3. 进入带有右下角“进攻”按钮的完整军队展示界面。
4. 截取未经裁剪、标注、缩放或压缩的原始横屏截图。
5. 文件严格命名为 `001.png` 至 `008.png`；编号必须与 `labels.txt` 对应。
6. 将图片放入本目录的 `images/` 子目录后整体交付。

如果某条链接因为超级兵尚未强化、装备未解锁或国服 ID 差异而不能完整复制，请记录编号和游戏提示，不要自行替换项目；该失败本身也是协议兼容性证据。

## 配置重点

- A（001/002）：六个未覆盖普通/超级兵种、三种未覆盖攻城机器、7 类法术临界行、三只未覆盖战宠和多件未覆盖装备。
- B（003/004）：巨石投手、超级巨人、隐秘哥布林、`x17` 数量以及行尾愤怒法术。
