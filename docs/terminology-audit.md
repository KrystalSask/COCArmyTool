# 18本简体中文术语审计

核对日期：2026-08-11。应用支持的 136 个常驻协议条目均在 `src/data/localization.zh-CN.ts` 中显式定义，并由 `src/data/gameData.test.ts` 和 `scripts/audit-game-catalog.mjs` 阻止英文回退、图片缺失或活动资源残留。

## 来源优先级

1. 用户提供的国服军队配置截图与国服分享链接。
2. Supercell 官方简体中文更新公告，例如 18 级大本营公告中的“陨石戈仑”和“图腾法术”。
3. 部落冲突 BWIKI 的国服/国际服对照页面及完整家乡军队导航。
4. 英文数据仅用于协议 ID、内部英文键和图片匹配，不作为中文译名来源。

## 图片资源审计

- 路径规则：`public/game-icons/<类别>/<协议 ID>.png`。
- 共 136 个运行时本地 PNG：兵种 49、攻城机器 9、法术 18、英雄 6、战宠 12、装备 42。
- 初始资源主要来自 `clash-of-clans-data` 0.16.0；该版本未覆盖的较新图标通过 BWIKI 与用户提供的国服截图补齐，包括废墟女巫、常驻陨石戈仑、愤怒法术和空中战车等。临时陨石戈仑 ID 167 已从运行时资源移除，常驻 ID 177 保留。
- 上游静态数据对常驻陨石戈仑携带了占位式大本营等级；生成器通过集中覆盖表将 ID 177 的解锁等级校正为官方公布的 17 本，并由图鉴测试与审计共同约束。
- 运行时不使用图片热链；所有文件均随应用本地提供。

图片中的游戏美术仍归 Supercell 所有；本项目依照 Supercell 粉丝内容政策作为非商业、非官方配兵辅助工具使用，并在界面中显示非官方声明。
